# Database (Oracle)

Foundation only: `ROLES` + `USERS`. No equipment, booking, sensor or audit tables yet.

## Layout

```
database/
├── README.md          # this file
├── schema/            # authored DDL, one file per step (01_roles_users.sql, ...)
├── data/              # authored reference-data seeds (01_roles_seed.sql, ...)
└── init/              # legacy PostgreSQL extensions file (unused for Oracle builds)
```

## How schema reaches the database

Single executable path — **Flyway on backend startup**:

```
database/schema/01_roles_users.sql  ──authored──▶  backend/.../db/migration/V2__roles_users.sql
database/data/01_roles_seed.sql     ──authored──▶  backend/.../db/migration/R__seed_roles.sql
```

- `V*__` = versioned migration, runs once. Never edit after it has applied anywhere.
- `R__` = repeatable migration, re-runs when its checksum changes (seeds use idempotent `MERGE`).
- `database/schema|data` are the human-reviewed sources; the `db/migration` copies are what actually executes. Keep them identical.

Standalone apply (without the backend) via SQL*Plus:

```bash
sqlplus labmarket/<password>@localhost:1521/XEPDB1 @database/schema/01_roles_users.sql
sqlplus labmarket/<password>@localhost:1521/XEPDB1 @database/data/01_roles_seed.sql
```

## Connection (environment variables only)

| Variable | dev default | prod |
|---|---|---|
| `DB_URL` | `jdbc:oracle:thin:@localhost:1521/XEPDB1` | **required, no default** |
| `DB_USERNAME` | `labmarket` | **required, no default** |
| `DB_PASSWORD` | `change-me-in-dev` | **required, no default** |

No credential is hard-coded in SQL, YAML or Java. Dev defaults are non-secret placeholders for a local XE.

Local XE setup (as SYSDBA):

```sql
ALTER SESSION SET CONTAINER = XEPDB1;
CREATE USER labmarket IDENTIFIED BY "change-me-in-dev";
GRANT CONNECT, RESOURCE TO labmarket;
ALTER USER labmarket QUOTA UNLIMITED ON USERS;
```

## Schema decisions

- PKs: `NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY` (Oracle 12c+), mapped as JPA `@GeneratedValue(IDENTITY)`.
- Time: `TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP`, mapped as `java.time.Instant`; app also sets them via `@PrePersist/@PreUpdate` (Oracle has no `ON UPDATE` clause).
- Booleans: `NUMBER(1)` with `CHECK (col IN (0,1))` Oracle convention.
- Uniqueness: `UNIQUE` constraints on `roles.name`, `users.username`, `users.email`; role names locked by `CHECK (... IN ('ADMIN','USER','VENDOR'))` (renamed from STUDENT/LAB_STAFF in V13).
- Passwords: column is `password_hash VARCHAR2(255)` — BCrypt-or-stronger hash. There is deliberately no plaintext column; seeds never contain user accounts.
